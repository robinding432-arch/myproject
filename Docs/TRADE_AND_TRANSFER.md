## 2. 玩家↔玩家 近距离给付

### 2.1 设计目标

> 星际公民中的 "Local Inventory Transfer" —— 两个玩家面对面，一方把物品/货币直接放进另一方背包，**不收税、不议价、即时完成**。

### 2.2 核心规则

| 规则 | 数值 | 理由 |
|---|---|---|
| 最大距离 | 400 cm (4m) | 面对面站在一起 |
| 需要视线 | ✅ 默认 | 防止穿墙给付 |
| 请求超时 | 30 秒 | 防止挂起请求 |
| 确认超时 | 15 秒 | 锁定后必须尽快确认 |
| 单次最大物品 | 20 件 | 防止一次倒空背包 |
| 单次最大货币 | 100 万 Cr | 防止一次性巨额转移 |
| 频率限制 | 10 次/分钟 | 防刷防自动化 |
| 装备给付 | ✅ 允许 | 可卸下装备直接给 |
| 任务物品给付 | ❌ 禁止 | 任务绑定物品不可转移 |

### 2.3 状态机

```
[Idle] ──发起──→ [Pending] ──接收方接受──→ [Accepted]
                                            │
                                      执行转移(服务端)
                                            │
                                            ↓
                                     [Completed] → 清理
                                     
[Pending] ──接收方拒绝──→ [Rejected] → 清理
[Pending] ──30s超时──→ [Expired] → 清理
[Pending] ──发起方取消──→ [Cancelled] → 清理
```

### 2.4 安全校验链

```
① 发起方必须有这些物品(服务端查背包)
② 发起方必须有足够货币(服务端查 CurrencyComponent)
③ 两人在 400cm 内(服务端测距)
④ 两人有视线(服务端射线检测)
⑤ 接收方身份匹配(NetID 比对)
⑥ 频率未超限(10次/分钟)
⑦ 执行时再次校验距离(防止移动后)
⑧ 全操作写日志(反作弊审计)
```

## 3. 玩家↔玩家 交易系统

### 3.1 设计目标

> 星际公民中的 "Trade Window" —— 两个玩家打开交易界面，**各自放物品/出价 → 双方锁定 → 双方确认 → 原子交换**。

### 3.2 与给付的区别

| 对比项 | 给付 (Give) | 交易 (Trade) |
|---|---|---|
| 场景 | 朋友间赠送 | 商业交易 |
| 议价 | ❌ 无 | ✅ 双方报价 |
| 货币流向 | 单向(免费) | 双向(等价交换) |
| 锁定机制 | 简单确认 | 双锁定 + 双确认 |
| 税收 | ❌ 无 | ✅ NPC 站点收税 |
| 复杂度 | 低 | 高 |

### 3.3 核心流程

```
玩家A 发起交易 → B 收到请求
  ↓
B 接受 → 双方打开交易窗口
  ↓
┌─ A 侧 ───────┐  ┌─ B 侧 ───────┐
│ 放物品 ×N    │  │ 放物品 ×M    │
│ 出价 Cr      │  │ 出价 Cr      │
│ [锁定]       │  │ [锁定]       │
└───────────────┘  └───────────────┘
  ↓ 双方锁定         ↓
  状态 → Locked
  ↓
  A 点击 [确认]    B 点击 [确认]
  ↓ 双方确认
  服务端原子执行:
    A 物品 → B 背包
    B 物品 → A 背包
    A 货币 - Tax → B 货币
    B 货币 - Tax → A 货币
  ↓
  [Completed] + 税收记录
```

### 3.4 税收系统

#### 税率配置

```cpp
FTradeTaxConfig DefaultTaxConfig;
DefaultTaxConfig.SellerTaxRate = 0.05f;    // 卖方 5%
DefaultTaxConfig.BuyerTaxRate  = 0.0f;     // 买方 0%(可配)
DefaultTaxConfig.MinTaxAmount   = 1.f;       // 最低 1 Cr
DefaultTaxConfig.MaxTaxAmount   = 10000.f;   // 封顶 1万 Cr
DefaultTaxConfig.TaxDestination = FName("Station"); // → 站点收入
```

#### 按站点覆盖

```cpp
// 黑市: 高税率
FTradeTaxConfig BlackMarket;
BlackMarket.SellerTaxRate = 0.15f;  // 15%
BlackMarket.TaxDestination = FName("Guild"); // → 军团金库

// 自由贸易站: 零税率
FTradeTaxConfig FreeTrade;
FreeTrade.SellerTaxRate = 0.0f;

// 注册
PerStationTaxConfig.Add(FName("ShadowMarket"), BlackMarket);
PerStationTaxConfig.Add(FName("ZurichFreePort"), FreeTrade);
```

#### 派系减免

| 关系 | 减免 |
|---|---|
| 友好派系 (Rep > 500) | 50% off |
| 同盟派系 | 100% off (免税) |
| 敌对派系 | 无减免(全额) |
| 同军团成员 | 30% off |

#### 税收去向

| 去向 | 效果 |
|---|---|
| `Station` | 站点收入 → 站主(玩家/AI)的银行账户 |
| `Faction` | 派系金库 → 影响派系经济实力 |
| `Guild` | 军团金库 → 军团可购买升级 |

### 3.5 NPC 站点交易

```cpp
// 玩家在 NPC 商店卖出(收卖方税)
Server_SellToNPCStation(Player, StationID, "Iron_Ore", 100, 10.f);
// → 检查物品 → 计算总额 100×10=1000Cr
// → 税收 1000×5%=50Cr
// → 玩家得到 950Cr
// → 审计日志: [NPC Sell] PlayerA → Station_X: Iron_Ore ×100 @10 | 税 50 (5.0%)

// 玩家在 NPC 商店买入(收买方税)
Server_BuyFromNPCStation(Player, StationID, "Medkit", 5, 50.f);
// → 检查货币 → 总额 5×50=250Cr
// → 买方税 250×0%=0 (默认买方不收)
// → 玩家支付 250Cr
// → 玩家获得 5 个 Medkit
```

## 4. 货运任务系统

### 4.1 设计目标

> 星际公民中的 "Cargo Hauling" —— 在太空港接任务 → 货物自动装船 → 飞到目的地 → 自动卸船 → 拿奖励。

### 4.2 完整流程

```
┌─────────────────────────────────────────────────────────┐
│ ① 飞到 NPC 空间站/太空港                              │
│ ② 走到任务板前 (≤500cm)                              │
│ ③ 查看可用任务:                                      │
│    ┌──────────────────────────────────────────────┐     │
│    │ 运输钛矿: 地球 → 火星                      │     │
│    │   货物: 200kg × 50 单位 = 10000kg         │     │
│    │   时限: 25 分钟                              │     │
│    │   奖励: 12,500 Cr                           │     │
│    │   ⚠️ 易腐: 15 分钟保鲜                      │     │
│    │   ★★☆☆☆ (Tier 2)                         │     │
│    └──────────────────────────────────────────────┘     │
│ ④ 点击 [接受]                                       │
│ ⑤ ★ 货物自动装入飞船货舱(带任务绑定)                 │
│ ⑥ 查看星图 → 设置导航 → 起飞                      │
│ ⑦ 飞行途中:                                          │
│    - HUD 显示货物保鲜倒计时                            │
│    - 易腐货物变红警告                                  │
│    - 可查看任务进度                                    │
│ ⑧ 到达目的地 → 飞船靠港 (≤2000cm)                   │
│ ⑨ ★ 货物自动卸下 → 任务完成                          │
│ ⑩ 奖励自动到账 + 派系声望 + 任务完成通知            │
└─────────────────────────────────────────────────────────┘
```

### 4.3 货物属性

| 属性 | 说明 |
|---|---|
| `ItemID` | 货物类型标识 |
| `Quantity` | 数量 |
| `UnitWeight` | 单件重量 (kg) |
| `UnitVolume` | 单件体积 (m³) |
| `bIsPerishable` | 是否易腐 |
| `PerishTime` | 保鲜剩余秒数 |
| `MissionID` | 任务绑定(不可丢弃/转移) |

### 4.4 易腐机制

```
货物保鲜倒计时:
  100% ─────────────────────── 0%
  │                              │
  │  正常飞行                     │ ⚠️ 警告区间(最后20%)
  │                              │ 货物开始变质
  │                              │
  ↓ 到 0 → 货物腐坏             
  → 任务失败
  → 货物从货舱消失
  → 无奖励
  → 声望小惩罚
```

### 4.5 任务生成

```cpp
// 自动生成(每 10 分钟)
GenerateAllStationMissions();
// → 遍历所有已注册站点
// → 每站生成 3 个任务
// → 随机配对目的地(非自身)
// → 随机难度 1~5
// → 随机货物 1~4 种
// → 33% 概率易腐
// → 距离决定奖励

// 手动生成
FName MissionID = GenerateCargoMission(
    FName("EarthStation"),   // 起点
    FName("MarsStation"),    // 终点
    3                       // 难度
);
```

### 4.6 难度与奖励

| Tier | 货物量 | 距离 | 时限 | 奖励范围 | 风险 |
|---|---|---|---|---|---|
| 1 ★ | 500~2000kg | 近 | 10~20min | 500~3000Cr | 无 |
| 2 ★★ | 2000~5000kg | 中 | 20~40min | 3000~8000Cr | 低 |
| 3 ★★★ | 5000~10000kg | 远 | 40~60min | 8000~20000Cr | 中 |
| 4 ★★★★ | 10000~20000kg | 很远 | 60~90min | 20000~50000Cr | 高 |
| 5 ★★★★★ | 20000kg+ | 极远 | 90min+ | 50000Cr+ | 极高 |

### 4.7 失败条件

| 原因 | 触发 | 后果 |
|---|---|---|
| 时限到期 | `TimeRemaining <= 0` | 任务失败，无奖励 |
| 货物腐坏 | `PerishTime <= 0` | 货物消失，任务失败 |
| 飞船被毁 | `OnShipDestroyed` | 货物丢失，任务失败 |
| 主动放弃 | 玩家点击放弃 | 可选归还货物 |
| 超出活跃上限 | >3 个活跃任务 | 无法接新任务 |

## 5. 飞船↔飞船 给付

### 5.1 场景

- 两艘飞船并排飞行（编队补给）
- 一艘飞船货舱满了，转到另一艘
- 战斗中击落敌人，队友捡拾掉落货物转移

### 5.2 规则

| 规则 | 数值 |
|---|---|
| 最大距离 | 1500 cm (飞船对接距离) |
| 转移内容 | 货舱物品 + 货币 |
| 单次上限 | 同玩家给付(20件/100万Cr) |
| 税收 | ❌ 无（飞船间不收税）|
| 频率限制 | 10次/分钟 |

## 6. 网络/安全架构

### 6.1 服务端权威

```
┌──────────────┐         RPC          ┌──────────────┐
│   Client A   │ ───Server_xxx──→ │              │
└──────────────┘                    │   Server     │
┌──────────────┐         RPC          │  (Authority) │
│   Client B   │ ───Server_xxx──→ │              │
└──────────────┘                    └──────────────┘
                                            │
                                            ↓
                                  所有校验在服务端执行:
                                  • 距离检测
                                  • 物品/货币校验
                                  • 频率限制
                                  • 税收计算
                                  • 审计日志
```

### 6.2 反作弊清单

| 攻击 | 防御 |
|---|---|
| 伪造距离 | 服务端 `GetActorLocation()`，客户端无法篡改 |
| 超速给付 | 频率限制(10次/分) |
| 负数货币 | `WithValidation` 检查 `Amount > 0` |
| 超额货币 | `MaxCreditsPerGive = 100万` |
| 物品复制 | 先 Remove 再 Add，服务端原子操作 |
| 任务货物转出 | `MissionID != NAME_None` 时禁止转移 |
| 穿墙给付 | 射线检测视线 |
| 交易中移动 | 每次操作重测距离 |

## 8. 配置参考

### 8.1 推荐税率表

| 站点类型 | 卖方税 | 买方税 | 去向 | 理由 |
|---|---|---|---|---|
| 自由贸易港 | 0% | 0% | — | 吸引贸易 |
| 商业中心 | 2% | 0% | Station | 低税促流通 |
| 标准空间站 | 5% | 0% | Station | 默认值 |
| 军事检查站 | 8% | 2% | Faction | 管控贸易 |
| 黑市 | 15% | 5% | Guild | 高风险高税 |
| 同盟站 | 0% | 0% | — | 同盟免税 |

### 8.2 推荐距离参数

| 场景 | 距离 | 理由 |
|---|---|---|
| 玩家给付 | 400 cm | 面对面伸手可及 |
| 玩家交易 | 500 cm | 交易窗口需要稍大空间 |
| 飞船给付 | 1500 cm | 飞船对接距离 |
| 飞船货运靠港 | 2000 cm | 大型飞船对接 |
| NPC 交互 | 300 cm | 按 E 交互距离 |
| 任务板 | 500 cm | 走过去阅读 |
