# 🚀 太空港与轨道站设计文档 v7.0

> 模仿《星际公民》的太空港体验，为 StellarSystem 带来沉浸式的地面-轨道-深空三级流转体验。

---

## 一、设计哲学

### 核心体验流程

```
深空飞行 → 抵达行星轨道 → 轨道空间站（补给/任务/量子旅行）
                              ↓ 电梯 30秒
                         地面太空港（社交/购物/机库）
                              ↓ 呼船终端
                         个人机库 → 登船 → 起飞
                              ↓ 电梯 30秒
                         回到轨道 → 继续深空冒险
```

### 三大空间层级

| 层级 | 位置 | 核心功能 | 对应现实 |
|------|------|---------|---------|
| **轨道层** | 行星轨道空间站 | 补给/修理/量子门/任务板 | 空间站 |
| **地面层** | 行星表面太空港 | 社交/购物/医疗/机库 | 机场/城市 |
| **电梯** | 轨道↔地面 传输 | 30秒沉浸式过渡 | 太空电梯 |

## 二、轨道空间站布局（OrbitalStationPlacer）

### 站位类型（5~6 个/行星）

| 站位 | 轨道类型 | 距行星表面 | 主要设施 | 访问频率 |
|------|---------|-----------|---------|---------|
| **LowOrbit** | 低轨道 300km | 飞船展示/低轨货运 | ⭐⭐⭐⭐⭐ |
| **Geosynchronous** | 同步轨道 | 量子门枢纽/通信 | ⭐⭐⭐⭐ |
| **Lagrange L4** | 拉格朗日L4 | 贸易站/前哨 | ⭐⭐⭐ |
| **Lagrange L5** | 拉格朗日L5 | 度假村/观测站 | ⭐⭐ |
| **TransferOrbit** | 转移轨道 | 物流枢纽/跃迁入口 | ⭐⭐⭐⭐ |
| **PolarOrbit** | 极地轨道 | 侦查/测绘/军事 | ⭐⭐ |

### 轨道运动

- 所有轨道站位按开普勒定律运动（简化版）
- 玩家在轨道站之间飞行时，目标在缓慢移动
- 增加了"拦截轨道"的驾驶乐趣
- 同步轨道站相对地面静止，方便往返

### 预设模板

| 行星类型 | 推荐模板 | 说明 |
|---------|---------|------|
| 宜居/温带 | `LushParadise` | 6个站位，全功能，观光+贸易 |
| 工业/荒芜 | `Industrial` | 4个站位，重货运+造船 |
| 军事/堡垒 | `Military` | 5个站位，重兵把守+军工 |
| 采矿/干旱 | `MiningOutpost` | 3个站位，精简高效 |
| 枢纽/首都 | `QuantumHub` | 3个站位，全是量子门 |

### 功能区详解

| 区域 | 功能 | 限制条件 | 互动 |
|------|------|---------|------|
| **电梯大厅** | 轨道↔地面 传送 | 无 | 30秒过渡动画 |
| **宿舍** | 角色休息/登出安全点 | 无 | 设置重生点 |
| **医院** | 治疗/复活/维生补给 | 需安检 | 付费治疗/免费急救 |
| **美食街** | 角色Buff/社交 | 无 | 各派系特色食物 |
| **商场** | 购买装备/消耗品/外观 | 声望≥0 | 派系专属商店 |
| **个人机库** | 停放/召唤飞船 | 需租赁/购买 | 呼船终端 |
| **公共展厅** | 浏览所有飞船型号 | 声望≥100 | 试驾/购买 |
| **会议室** | 组队/派系会议 | 声望≥300 | 创建队伍/派系管理 |
| **海关** | 安全检查/通关 | 必须检查 | 违禁品扫描 |
| **地面交通** | 前往其他城市/探索 | 无 | 快速旅行 |

### 电梯系统

```
轨道站 ──[电梯启动]──→ 黑屏+音效(15秒) ──→ 到达地面
地面港 ──[电梯启动]──→ 黑屏+音效(15秒) ──→ 到达轨道
```

- 电梯期间锁定玩家输入
- 显示加载画面（星球全景/空间站内部）
- 完成后解锁输入，播放环境音效
- 可付费加速（5秒 快速电梯，费用=标准租金的10%）

## 四、呼船终端系统

### 使用流程

```
1. 玩家进入个人机库
2. 走到呼船终端（交互键 E）
3. 打开呼船界面 → 显示拥有的飞船列表
4. 选择飞船 → 点击"呼叫"
5. 飞船从轨道站/远方飞入 → 60秒到达
6. 飞船降落在停机坪 → 玩家登船 → 起飞
```

### 呼船时间

| 飞船类型 | 基础到达时间 | 加速后 |
|---------|------------|--------|
| 小型侦察机 | 30秒 | 10秒 |
| 战斗机 | 45秒 | 15秒 |
| 货船 | 60秒 | 20秒 |
| 探索船 | 60秒 | 20秒 |
| 战舰 | 90秒 | 30秒 |

### 加速呼船

- 费用 = 飞船价值的 5%
- 处理时间缩短为 1/3
- 在保险索赔时自动加速

## 五、保险与索赔系统

### 保险等级

| 等级 | 月费(例：战斗机) | 免赔额 | 有效期 | 索赔次数 | 特色 |
|------|-------------------|--------|--------|---------|------|
| **None** | 0 | 100% | - | 0 | 无保障，全损自负 |
| **Basic** | 120 | 10% | 90天 | 5次 | 入门级 |
| **Standard** | 300 | 5% | 6个月 | 5次 | 主流选择 |
| **Gold** | 600 | 2% | 1年 | 10次 | 高频玩家 |
| **Platinum** | 1200 | 0% | 终身 | 无限 | VIP |
| **Fleet** | 2400 | 0% | 终身 | 无限 | 组织共享 |

### 覆盖范围

| 类型 | 倍率 | 覆盖内容 |
|------|------|---------|
| Hull Only | 1.0x | 仅飞船船体 |
| Hull + Cargo | 1.3x | 船体+货舱物品 |
| Full Coverage | 1.6x | 船体+货物+装备 |
| Combat | 2.0x | 包含PvP战斗损失 |
| Piracy Loss | 2.5x | 包含被海盗击毁 |

### 索赔流程

```
载具损毁 → 自动检测 → 创建索赔单 → 处理中(30~120秒)
                                            ↓
                                    索赔完成 → 新载具出现在机库
```

### 自动触发

- 飞船HP=0 → 自动提交索赔
- 玩家离线超过5分钟且飞船无主 → 标记"失踪" → 可手动找回
- PvP击杀 → 根据保险类型决定是否覆盖

### 找回 vs 索赔

| 情况 | 操作 | 费用 | 时间 |
|------|------|------|------|
| 飞船卡住/掉线 | 找回（Recover） | 免费 | 即时 |
| 飞船被毁（有保险） | 索赔（Claim） | 免赔额 | 30~120秒 |
| 飞船被毁（无保险） | 重新购买 | 全价 | 即时 |
| 飞船被盗 | 找回+追踪 | 10%价值 | 5分钟 |

## 六、组队系统

### 队伍规模

| 队伍类型 | 最大人数 | 说明 |
|---------|---------|------|
| Solo | 1 | 单人 |
| Duo | 2 | 双人小队 |
| Squad | 4 | 标准小队 |
| Platoon | 8 | 大型队伍 |
| Company | 16 | 组织级别（需派系） |

### 权限层级

```
Leader (队长)
  ├── 邀请/踢人
  ├── 转让队长
  ├── 设置编队
  ├── 设置共享模式
  └── 分配战利品

Officer (军官)
  ├── 邀请玩家
  ├── 踢人（需队长同意）
  └── 标记目标

Member (队员)
  ├── 接受/拒绝邀请
  ├── 离开队伍
  └── 使用队伍语音

Recruit (新兵)
  └── 仅基础通信
```

### 共享模式

| 模式 | 效果 |
|------|------|
| **Loot Sharing** | 击杀掉落按贡献分配 |
| **XP Sharing** | 队友获得 50% 经验共享 |
| **Reputation Sharing** | 派系声望任务共享进度 |
| **Radar Sharing** | 全队共享雷达/地图标记 |
| **Resources** | 资源节点采集量共享 |
| **All** | 以上全部 |

### 编队阵型

| 阵型 | 间距 | 适用场景 |
|------|------|---------|
| Free | - | 自由飞行 |
| V Formation | 500m | 战斗机编队出击 |
| Line Abreast | 800m | 轰炸机横扫 |
| Column | 300m | 穿越狭窄区域 |
| Wedge | 600m | 搜索/探索 |
| Diamond | 500m | 全方位警戒 |

### 语音系统

- **Push-to-Talk** 默认模式
- 近距离语音（1000m 内自动开启）
- 队伍语音（全地图）
- 指挥频道（队长+军官）
- 可单独静音任意队员

### 目标标记

- 任何队员可放置标记（最多3个）
- 全队可见 3D 标记 + 距离
- 标记类型：攻击/集合/观察/自定义
- 队长标记自动广播给所有人

### 跨派系组队

| 派系A | 派系B | 能否组队 |
|--------|--------|---------|
| 地球帝国 | 翠绿商会 | ✅ 可以（友好） |
| 地球帝国 | 绯红海盗 | ❌ 不可以（敌对） |
| 绯红海盗 | 游牧部落 | ✅ 可以（海盗例外） |
| 虚空学者 | 任何派系 | ✅ 可以（中立） |
| 自动蜂群 | 任何派系 | ❌ 不可以（敌视所有） |

## 七、技术实现要点

### 网络架构

```
Client (Player) ──RPC──→ Server (Authority)
                            │
                            ├── PartySystem (WorldSubsystem)
                            ├── InsuranceManager (WorldSubsystem)
                            ├── OrbitalStationPlacer (Actor)
                            └── PlanetarySpaceport (Actor)
```

### 关键 RPC

| 函数 | 方向 | 验证 | 说明 |
|------|------|------|------|
| `Server_CallShip` | Client→Server | ✅ | 呼船请求 |
| `Server_RetrieveShip` | Client→Server | ✅ | 登船 |
| `Server_UseElevator` | Client→Server | ✅ | 电梯传送 |
| `Server_FileClaim` | Client→Server | ✅ | 提交索赔 |
| `Server_CreateParty` | Client→Server | ✅ | 创建队伍 |
| `Server_InvitePlayer` | Client→Server | ✅ | 邀请玩家 |

### 性能考虑

- 轨道运动每 0.5 秒更新一次（非每帧）
- 呼船队列批量处理（1秒间隔）
- 队伍位置更新 0.5 秒间隔
- 保险索赔处理在服务器 Tick 中批量更新
- 太空港区域碰撞体使用 Overlap 而非 Block
